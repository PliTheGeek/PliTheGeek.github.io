# Rafli Dhafin Kamil - CV

A minimalist, static CV website designed for GitHub Pages. It has no build step and can be deployed directly from the repository root.

The personal brand mark lives in `brand-mark.svg` and is used in the header and browser tab. The full name remains the main hero identity so the CV is still clear when printed or scanned.

## Before publishing

- Keep `profile.png` in the project root for the profile portrait.
- Review the project descriptions and repository links in `index.html`.
- Confirm the education dates and GPA are current.

The Education section includes the Bachelor of Software Engineering from Telkom University, Purwokerto Campus, plus Software Engineering at Telkom Jakarta Vocational School, graduated 2022. Keep the dates and GPA current before publishing.

## Current positioning

The page presents Rafli as a fresh Software Engineering graduate focused on JavaScript web development, Flutter, IoT monitoring, MSME-oriented software, and practical infrastructure work with Docker, CI/CD, Linux, Nginx, Grafana, and Azure.

## GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages** in that repository.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select the default branch and `/ (root)`.
4. Save. GitHub will provide the published URL.
